# Un Denis Presque Parfait

Jeu de notation familial façon "Un dîner presque parfait" : chaque participant reçoit un jour où il cuisine pour les autres, qui le notent ensuite sur plusieurs critères (goût, présentation, originalité...).

## Fonctionnement

1. **Configuration** (panel admin) : ajoute les participants, planifie leurs jours, définis les critères de notation
2. **Chaque jour** : les convives notent le cuisinier du jour depuis leur téléphone
3. **À la fin** : classement automatique avec podium et détail des notes

## Accès

- **Vue publique** : accessible via la sidebar une fois l'add-on démarré
- **Panel admin** : accessible sur `/panel.html` depuis l'URL de l'add-on
